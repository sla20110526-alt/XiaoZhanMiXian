# 正义坊场景远景修订01：生成记录

日期：2026-10-19
方式：内置 ImageGen；每版先重构空景，再局部修正天空及门楼尺度。

本轮调整：减少建筑，扩大前中景连通地面，门楼降为侧后方小比例地标；保留4:3、微缩模型与老电视特摄风格。场景为空景，不含人物、怪物或特效。

参考：图片/分镜/分镜06.png（取景与色调，排除角色、光束、密集楼群与真实天空）；图片/参考/正义坊.jpg（门楼建筑形态）。

## 横向宽街版：初次生成 Prompt

任务：重做昆明正义坊微缩城市空景，横向4:3单幅，摄影棚内实物模型特摄摄影，1980年代彩色电视播映质感。
参考绑定：输入第一张《分镜06》仅参考巨物视点的广阔横向取景与旧电视色调。彻底移除第一张中的男孩、怪物、光束及动作元素；显著减少原图建筑密度和树木密度，不复制通讯塔，不复制真实云。输入第二张《正义坊》只提取门楼的建筑形态：中间高、两边逐层降低的五组橙黄琉璃瓦翘檐、红柱、青蓝彩画横梁、灰色石柱脚、红底金字匾，匾额若可见按照片写左“義”右“正”。将门楼制作成同一场景内的小型实体微缩模型。
共同空间要求：这是远景城市环境空镜。相机向后退远，完整呈现宽阔场地，不做门楼近景或地标特写。左右和远处仅约6至9组低层建筑模型，1至4层为主，天际线低，建筑之间明显留出间隔。建筑全部小比例、低于画面中央高度，不要大楼墙占据前景，不要连绵密集楼海，不要无限延伸的城市背景。宽阔连续平整的地面从前景贯通中景，中央约60%画面横向范围没有建筑、车辆、树木或杂物遮挡。不要把场景做成荒地或停车场，仍有少量昆明旧城的灰瓦、木窗、抹灰街屋和路缘。零散树木只在边缘。正义坊位于一侧中远景，仅占总画宽约12%，明显小于上一轮，融入城市尺度，不处于中轴中心。
材质与摄影：实拍的手工木板、石膏、纸板制作建筑，哑光漆、简化门窗、可见轻微手工制作痕迹；小型海绵树冠。接地阴影可信，但不做写实城市航拍，不做游戏3D、不做等距沙盘展示。机位在微缩楼顶稍上方，向前平视的宽景，轻微俯视地面，保持建筑竖直；不是无人机鸟瞰。单一棚灯模拟左上方日光，柔和填充。低饱和米灰、砖红、灰瓦、暗绿。轻微胶片颗粒、温和褪色与镜头柔度，细节仍可辨，不要重VHS故障。
天空关键：上半部的大面积天空必须是摄影棚弧形背景墙上的手绘天幕，均匀哑光粉蓝，少量非常淡的横向白色笔刷云痕，平面颜料质感和简单渐变；没有写实云体、云海、壮观积云、自然卷云照片或体积光。远处如有山，仅为极淡平面绘景轮廓。不要露出灯架、棚顶、工作人员、画布褶皱或舞台边缘。
保持空景：不出现任何人物、怪兽、汽车、战斗光效、标题、边框、拼图、分屏或黑边。
本张版本：横向宽街。宽阔的旧城灰色街面横向贯穿画面底部和中部，略带向远处的透视，远近地面宽阔完整。街道两边退后布置少量小比例低楼；左边两组三层灰白抹灰楼和一组双层灰瓦木窗老商铺，右边两组三层砖灰楼和一组灰瓦小屋，建筑不拥挤。在左侧中远景一条支路处放置缩小的正义坊门楼，整体宽度约画宽12%，不要门楼占满视野；中央远处仅一两组更小的矮屋。画面上方约50%是棚绘粉蓝天空，地面与稀疏城市占下方50%。前景边沿可以有很低的局部路缘或一角小屋屋顶，但不遮挡中心广阔地面。城市横向展开，清晰体现很宽的空间和大面积留空。

## 两版最终局部修订 Prompt

编辑这张已生成的微缩城市空景，只修正两个明确问题，其余构图、机位、建筑、道路、光影、老电视色彩、4:3尺寸必须保持一致。
1. 天空替换：彻底删除天空里现在所有真实自然云纹理、碎絮状卷云、细密白色云群及左上角太阳光晕。替换为非常简洁的摄影棚手绘天幕：近乎无云的哑光浅灰粉蓝色大背景，轻微而宽阔的颜料色调变化，至多两道非常淡的模糊白色刷痕。它是平整绘景墙，远看像老特摄片人工天空，不能是现实天空照片；无需画出边界、褶皱、接缝或棚架。地面受光保持不变。保留远处淡山轮廓并将其略平面化。
2. 将画面一侧的正义坊门楼整体再缩小约40%，缩小后占总画宽约12%至14%，保留其红柱、五组高低屋檐、金瓦青蓝彩画和金字红匾的既有建筑形态。放在当前所在侧道路稍更后的位置，补齐缩小后周围露出的天空、地面和少量原有背景。它应只是环境中的小比例地标，与周围低楼自然共存。不要把门楼移到中央、不要新增门楼。
保持前中景宽阔连通的空地及稀疏楼房安排，保持物理微缩建筑和模型树材质，继续无人、无怪物、无光束、无车辆。不要添加其他元素，不要加文字说明，不要改变为多联图。
