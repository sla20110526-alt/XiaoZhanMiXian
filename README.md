## 当前制作方向

- 4:3横画幅。
- 20世纪70年代至80年代早期彩色电视真人特摄节目观感。
- 摄影棚实体微缩城市、手工纸板儿童服装、真人穿戴怪物皮套、早期光学合成特效。
- 标准清晰度感知解析力、全局略软、有限动态范围、轻微色度溢出和细密模拟噪点。
- 不采用现代4K/HDR、地产宣传片、游戏CG或重度VHS故障风格。
